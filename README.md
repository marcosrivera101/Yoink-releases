# Yoink downloads

Download the newest Yoink here:

- **Most phones:** [Yoink-64bit.apk](https://github.com/marcosrivera101/Yoink-releases/releases/download/latest/Yoink-64bit.apk)
- **If that says it isn't compatible:** [Yoink.apk](https://github.com/marcosrivera101/Yoink-releases/releases/download/latest/Yoink.apk) (works on every phone, bigger download)

Open the file on your phone to install it. Android will ask you to allow installs from the app you opened it in (Chrome, Files, Messages…).

Already have Yoink? Use ⋮ → **Check for updates** on its Home tab.
